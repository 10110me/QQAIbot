# 数据与权限

仅接收白名单群；私聊默认关闭。外部内容、网页、PDF、OCR 和群公告都只是数据，不能授予权限或修改系统策略。昵称不能成为管理员身份。

群 collect_messages=false 时，SQL 不写原文，只保留去重元数据，原文临时留在处理内存；关闭后不自动抹除旧记录。用户请求和授权上下文会发送给你配置的模型供应商，群成员应知晓该采集和处理范围。

长期记忆有源记录、主体、scope、状态和版本。跨群个人记忆默认关闭，需要本人检索同意、目的群披露同意和目的群策略三重检查。群文件与私聊不会因此共享。建立个人 Embedding 还需要用户单独开启向量授权；撤销会删除对应索引。

自动事实整理只有在群 memory_extract 开启后运行，只允许来自同一主体本人的明确陈述，校验来源、置信度和撤回状态，不自动把群聊说法升级成公共知识。公开文档需 owner 显式确认 provenance/verified/license。

/记忆 删除 会清理事实、对应向量、相关回放快照和候选；不会自动删除全部原始聊天。/隐私 删除我的数据 或 owner 的用户数据删除 API 会清理当前数据库中源正文、个人记忆、向量、研究与媒体，并撤销授权；原群情景摘要按源失效。独立备份按保留计划处理。

保留期按 OSA_RETENTION_DAYS 自动清理原始正文、情景、媒体和研究。发送记录是独立审计资产，未自动视为原始聊天一起清空。已经发到 QQ 的消息不能自动追回。

DeepSeek profile 保存账号登录 Cookie，仅挂载给专用浏览器。研究删除会尝试清理浏览器 Worker 的本地问答缓存，离线时使用删除待办重试；DeepSeek 网站账号历史需要在其网页中另行管理。不得宣称本地删除已经迫使第三方删除。

owner 可以访问所有管理数据与账号桌面；额外 reviewer/viewer/moderator/admin 只获得其群范围内的消息或群管理能力，不获得全局浏览器、密钥路由与插件管理权限。管理 Token 不放在 URL，不写浏览器持久存储；浏览器映射使用短期 HttpOnly Cookie。

默认本机监听；公网部署需 HTTPS 与受控代理。日志只记录必要 ID、状态和错误类型，不记录密钥值或供应商异常原文。下载采用公共地址/DNS 连接校验和流量上限，执行与解析不在拥有主应用密钥的进程运行。
