# 批量替换功能模型

进入模型配置中心的「给功能分配模型」，点击「批量替换模型」，选择原模型及模型池中已添加的目标模型。确认影响的功能列表后，点击「一键替换」，所有绑定原模型的功能同步更新，无须逐个修改。

该操作仅替换功能绑定，不重命名或删除模型池中的模型。其余模型的相对顺序、调度策略、生成参数和超时设置不变。替换后存在重复模型时保留第一次出现的位置；未使用原模型的功能不受影响。目标模型应支持相应功能，例如图片、语音或向量能力。

接口为所有者专用的 `POST /api/v1/config/tasks/replace-model`，参数为 `source_model`、`target_model` 和必填 `revision`。所有修改通过一次版本校验和配置保存提交，其他页面已更新配置时返回 409，不部分修改。保存后立即生效并持久化。
