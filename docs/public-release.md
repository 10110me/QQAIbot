# 汐言脱敏发布

## 发布边界

公开版本只包含代码、Worker、迁移、测试、模板和经选择的文档。`.env`、数据库、加密配置及密钥、浏览器登录态、聊天导出、备份、临时目录、附件和个人运维报告不能发布。

测试使用合成身份，不把线上 QQ、主人绑定、群号或真实聊天复制为样例。Nova 是示例角色，主人关系由部署者的私有配置决定。

## 导出

```bash
python scripts/public_release.py --output dist/tidetalk
python scripts/package.py
```

导出必须使用新目录，不覆盖原目录。ZIP 与 SHA-256 生成在 `dist/`。`public-source-manifest.json` 只记录公开文件的相对路径与哈希，不记录凭据、用户名、部署路径或扫描值。

新增代码目录、脚本或文档时，应审查后更新白名单，不要递归复制全工程。符号链接与目录连接会被拒绝，防止越界读取。

检查覆盖私钥、常见 Token、API Key、JWT、个人 QQ 邮箱、Windows 用户目录与 NAS 卷路径。还会从本机 `.env*` 和本地加密配置读取已知凭据用于比对，**不将值写入报告**。可在被忽略的 `.public-release-private.json` 中添加私有字符串列表。

自动检查不能替代人工审查，不能识别所有秘密。另需核对样例、Git 元数据、归档、构建上下文和服务地址。测试固定 Token 不得用于真实部署。

## GitHub 历史替换

从审核后的导出目录建立独立 Git 仓库，用不含私有作者邮箱的身份创建根提交；核对远端与旧 SHA 后，使用 `--force-with-lease` 替换分支。不要从部署仓库推送，也不要用 `--mirror` 删除无关引用。

改写分支不能保证清除 GitHub 缓存、PR 引用、Fork、他人克隆、Actions 产物或发布附件。若曾公开凭据，必须撤销并轮换；缓存清除需另行处理。分支/标签与 Issues、Releases、Wiki、Actions 的清理是不同操作，需明确范围。

本地工程和 NAS 数据独立保留，不因发布删除配置、记忆、会话或持久卷。
